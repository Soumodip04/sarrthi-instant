## 🌟 Overview

**Sarrthi Instant** is engineered to turn skeptical strangers from cold outreach (Email, LinkedIn, DMs) into booked strategy calls. Designed with an intentional balance of high-trust international aesthetics, lightning-fast performance, transparent pricing, and conversion science.

Unlike generic agency templates or bloated theme builders, this site is built from scratch with Next.js 16 (Turbopack), custom design tokens, and purpose-built interactive tools that demonstrate competence before a client even gets on a call.

---

## 🚀 Key Features

### 1. 🌐 Global Operations & Timezone HUD
- **Live International Clocks:** Real-time synchronized clocks for **London (GMT)**, **New York (EST)**, and **Sydney (AEST)**.
- **Availability Status Indicator:** Pulsing live availability badge showing available project slots for the month.
- **Multi-Currency Engine:** Instant price conversions across **USD ($)**, **GBP (£)**, **EUR (€)**, and **AUD ($)** across all estimator and pricing tiers.
- **Quick-Copy Contact:** One-click clipboard copy for direct email inquiries.

### 2. 🎯 High-Conviction Hero Section
- **Benefit-First Value Proposition:** Clear, human-centric messaging for business owners (no confusing developer jargon).
- **Live Proof HUD Card:** Highlights verified metrics (`+186% Google Search Growth`, `< 0.6s Load Time`, `#1 Local Maps Rank`, `21-Day Kickoff to Live`).
- **Social Proof Badges:** Clear geographical targeting across the UK, US, Australia, and Canada.

### 3. 💼 Interactive Project Vault (Case Studies)
- **Live Website Mockup Viewport:** Interactive desktop & mobile preview frame switcher.
- **Speed & Results Diagnostic View:** Side-by-side core vitals and business outcomes for recent builds:
  - 🇬🇧 **Finova Capital** (London) — Investment & Financial Services
  - 🇺🇸 **Apex Global Logistics** (Chicago) — Freight & Supply Chain
  - 🇦🇺 **Lumina Skin Science** (Sydney) — E-Commerce & Routine Finder
  - 🇨🇦 **Veritas Legal Group** (Toronto) — Corporate Litigation Practice

### 4. ⚡ 30-Second Live Website Audit Tool
- Interactive analyzer that lets prospective clients input their URL and select their target country.
- Simulates real-time diagnostics:
  - Mobile Loading Speed & Potential Visitor Loss
  - Google Structured Data / Local Business Schema
  - Missed High-Intent Search Keyword Opportunities
  - Projected Conversion Lift with a Modern Build

### 5. 🛠️ Strategic Service Pillars
- **Two Core Disciplines:** Custom Web Engineering + High-Intent Google SEO.
- **Contrast Matrix:** Side-by-side breakdown comparing traditional agency shortcomings vs. *The Sarrthi Instant Way*.
- **Clear Deliverables:** 4 transparent deliverables per service pillar with associated tech stacks.

### 6. ⏱️ 4-Phase Delivery Sprint (Process)
- **Phase 01:** Blueprint & Strategic Scope *(Days 1–4)*
- **Phase 02:** High-Fidelity Design & Prototype *(Days 5–10)*
- **Phase 03:** Next.js Engineering & Speed Optimization *(Days 11–17)*
- **Phase 04:** Quality Assurance, Launch & Google Indexing *(Days 18–21)*
- **Client Time Requirement:** Explicitly displays the minimal commitment needed from the business owner (under 3 hours total).

### 7. 🌍 Friction-Free Remote Operating System
- Dedicated trust architecture addressing the 4 key concerns of hiring remote/offshore agencies:
  - **Overlapping Working Hours** (4–6 hours guaranteed live overlap)
  - **Asynchronous Video Updates** (Loom walkthroughs instead of endless meetings)
  - **Secure Local Invoicing** (Multi-currency Stripe payments)
  - **100% IP & Code Ownership** (Full handover of repository and assets)

### 8. 🧮 Real-Time Project Scope & Cost Estimator
- Configurable interactive calculator allowing visitors to adjust:
  - Project Type (New Build, Redesign, SEO Growth, Full Package)
  - Page Count (1–3 Pages, 4–8 Pages, 10+ Pages)
  - Add-ons (Instant Quote Calculator, Local Google Maps Setup, 10-Day Fast Track)
- Computes estimated delivery timeline and investment in the visitor's selected local currency.

### 9. 💳 Transparent Fixed Pricing & Inclusions
- Transparent sprint packages with clear **What's Included** and **What's Not Included** sections.
- Featured high-contrast dark card for the flagship tier (**Full Growth Engine**).

### 10. ❓ Dynamic FAQ with Search & Filtering
- Filterable by topic category: *All*, *General*, *How We Work*, *Payments & Safety*, *SEO & Google*.
- Live real-time search input for instant answers to client objections.

### 11. 📅 15-Minute Strategy Booking Modal & Intake Hub
- Two-step interactive booking modal for instant consultation scheduling.
- Direct communication channels (WhatsApp, Email) and structured project intake form.

## 🛠️ Getting Started

### Prerequisites
- **Node.js:** `v18.17.0` or higher
- **npm** / **pnpm** / **yarn**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Soumodip04/sarrthi-instant.git
   cd sarrthi-instant
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Visit [http://localhost:3000](http://localhost:3000) to view the application.

### Production Build

To test the production build locally:

```bash
npm run build
npm run start
```
